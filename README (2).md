# Папка /public

## hero.mp4
Основной hero-видео. Положите сюда файл с именем `hero.mp4` — он подхватится автоматически в Hero-секции.

Источники: пользователь сообщит имя нужного видео в отдельном сообщении и пришлёт файл.

## hero-poster.svg
Запасной постер, показывается до загрузки видео (или если видео ещё не загружено).

## products/
Сюда можно складывать фотографии товаров, чтобы не зависеть от внешнего CDN с auth_key (которая может истечь).
В `src/data/products.ts` потом заменяем `images.main` / `images.hover` на локальные пути вида `/products/ten-20-main.png`.
