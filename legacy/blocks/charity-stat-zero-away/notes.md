# Блок: статистический кубик «0 уходит на сторону» в секции #charity

Статус: archived
Дата архивации: 2026-09-25
Причина удаления: не показываем этот показатель публично.

## Где находился блок

Исходный файл: `src/components/site/Charity.tsx` (секция `<section id="charity">`,
левая колонка, блок «Impact stats» под цитатой).

Селектор / тексты для поиска:
- массив `IMPACT_STATS`, 3-й элемент: `{ v: "0", l: "уходит на сторону" }`;
- рендер: контейнер `div.grid.grid-cols-3.gap-3.mb-6`, кубик:
  ```html
  <div class="border border-[var(--olive-dark)] bg-[rgba(92,107,60,0.08)] p-3 text-center">
    <div class="font-display text-[1.5rem] font-bold text-[var(--olive-light)] leading-none mb-1">0</div>
    <div class="font-mono-brand text-[0.52rem] uppercase tracking-[1px] text-[var(--text3)] leading-tight">уходит на сторону</div>
  </div>
  ```

## Что было удалено

- элемент `{ v: "0", l: "уходит на сторону" }` из массива `IMPACT_STATS`;
- кубик целиком (число «0» + подпись «уходит на сторону»).

## Что осталось в публичной версии

Два кубика в ряд:
1. `500+` — комплектов передано
2. `12` — заявок выполнено

Контейнер переведён с `grid-cols-3` на `grid-cols-2` — два кубика равномерно
занимают весь ряд на всех брейкпоинтах (в т.ч. мобильных), пустоты нет.

## Зависимости

- CSS-классы: классы кубика остались в `map` — используются двумя
  оставшимися кубиками;
- JS-логика: нет;
- Данные: только строковые литералы удалённого элемента массива;
- Ссылки / якоря: нет.

## Как вернуть блок

1. Открыть `legacy/blocks/charity-stat-zero-away/original-component.tsx`
   (полный исходник Charity.tsx на момент архивации).
2. В `src/components/site/Charity.tsx` добавить в массив `IMPACT_STATS`:
   ```ts
   { v: "0", l: "уходит на сторону" },
   ```
3. Контейнер статистики вернуть на `grid grid-cols-3 gap-3 mb-6`
   (строка с комментарием «Impact stats» в компоненте).
4. Пересобрать статику: `bun run build`.
5. Проверить адаптив (3 кубика в ряд на мобильных были тесными — при
   возврате убедиться, что подписи читаются) и консоль браузера.
