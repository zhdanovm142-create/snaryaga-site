# Блок: количество подписчиков в рассылке

Статус: archived
Дата архивации: 2026-09-25
Причина удаления: не показываем публичное число подписчиков и связанное с ним
социальное доказательство (аватары-«кружки» + «5000+ подписчиков»).

## Где находился блок

Исходный файл: `src/components/site/Newsletter.tsx` (компонент секции рассылки,
подключается в `src/app/page.tsx` через `next/dynamic`).

Селектор / классы для поиска:
- контейнер: `div.flex.items-center.gap-4.flex-wrap` сразу после `<ul>` преимуществ;
- аватары: `div.flex.-space-x-2` с четырьмя `<span>` кружками
  (цвета `#5c6b3c`, `#8b7355`, `#3d4728`, `#6b6040`);
- текст: `<span class="text-[0.75rem] text-[var(--text3)]">` с вложенным
  `<span class="text-[var(--olive-light)] font-bold">5000+</span> подписчиков`.

## Что было удалено

- 4 аватара-кружка (`div.flex.-space-x-2`, aria-hidden) — имитация подписчиков;
- текст «**5000+** подписчиков»;
- обёртка `div.flex.items-center.gap-2` вокруг аватаров и текста.

## Что осталось в публичной версии

- заголовок «Рассылка» и «Новинки и полевые тесты — на почту»;
- список из 4 преимуществ (BENEFITS: 🔔 📦 📊 ✅);
- бейдж «1 письмо / месяц» с пинг-индикатором (не связан с числом подписчиков);
- форма e-mail + кнопка «Подписаться» (FormSubmit.co);
- подпись про политику конфиденциальности.

Контейнер бейджа переименован в комментарий от
`{/* Social proof + frequency */}` → `{/* Frequency badge */}`, сама разметка
бейджа не менялась.

## Зависимости

- CSS-классы: только tailwind-утилиты внутри удалённого фрагмента, общие
  стили не затронуты;
- JS-логика: нет (фрагмент статический);
- Данные: нет (массив цветов аватаров был инлайном в JSX);
- Ссылки / якоря: нет.

## Как вернуть блок

1. Открыть `legacy/blocks/newsletter-subscriber-count/original-component.tsx`
   (полный исходник Newsletter.tsx на момент архивации).
2. Скопировать фрагмент между комментариями `{/* Social proof + frequency */}`
   и закрывающим `</div>` перед `</div>` левой колонки (строки ~101–127
   оригинала: контейнер `flex items-center gap-4 flex-wrap` с аватарами,
   текстом «5000+ подписчиков» и бейджем).
3. Вставить в `src/components/site/Newsletter.tsx` после `</ul>` преимуществ
   вместо текущего блока `{/* Frequency badge */}`.
4. Пересобрать статику: `bun run build`.
5. Проверить адаптив (badge-строка переносится на мобильных через
   `flex-wrap`) и консоль браузера.
