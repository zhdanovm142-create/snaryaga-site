# Блок: карточка «Прозрачность» в секции #charity

Статус: archived
Дата архивации: 2026-09-25
Причина удаления: карточка убрана из публичной секции волонтёрской жизни
команды (сведена информация о публичной отчётности по помощи).

## Где находился блок

Исходный файл: `src/components/site/Charity.tsx` (секция `<section id="charity">`).

Селектор / тексты для поиска:
- массив `CHARITY_FEATS`, 4-й элемент:
  ```ts
  {
    icon: "💬",
    title: "Прозрачность",
    desc: "Отчёты о направленной помощи — по запросу.",
  }
  ```
- рендер: карточка в сетке `grid grid-cols-1 sm:grid-cols-2 gap-4` (правая
  колонка секции), последняя (4-я) позиция.

## Что было удалено

- элемент массива `CHARITY_FEATS` с `title: "Прозрачность"`;
- вместе с ним исчезла карточка с иконкой 💬 и текстом
  «Отчёты о направленной помощи — по запросу.».

## Что осталось в публичной версии

3 карточки в сетке `sm:grid-cols-2`:
1. 🤝 Сборы снаряжения
2. 📦 Гуманитарная помощь
3. 🏕️ Сообщество — **растянута на освободившееся место** через
   `sm:col-span-2` (последняя карточка в `CHARITY_FEATS.map` получает класс
   `sm:col-span-2`; на мобильных сетка одноколоночная, класс не влияет).

Пустых ячеек в сетке нет.

## Зависимости

- CSS-классы: общие классы карточек (`group border … hover:-translate-y-1`)
  остались — используются оставшимися тремя карточками;
- JS-логика: нет;
- Данные: только строковые литералы внутри удалённого элемента массива;
- Ссылки / якоря: нет.

## Как вернуть блок

1. Открыть `legacy/blocks/charity-transparency-card/original-component.tsx`
   (полный исходник Charity.tsx на момент архивации).
2. В `src/components/site/Charity.tsx` добавить 4-м элементом массива
   `CHARITY_FEATS`:
   ```ts
   {
     icon: "💬",
     title: "Прозрачность",
     desc: "Отчёты о направленной помощи — по запросу.",
   }
   ```
3. Убрать условную выдачу `sm:col-span-2` последней карточке в `map`
   (иначе «Сообщество» останется растянутой и сетка сломается).
4. Пересобрать статику: `bun run build`.
5. Проверить адаптив (сетка 2×2 на sm+) и консоль браузера.
